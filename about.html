關於夜市小吃圖鑑

這是一個用 AGENTS.md 驅動的小型內容網站。網站的程式只寫一次，之後每新增一道小吃，只要照著同一套規則補上「一個 Markdown 檔 + 一筆 JSON 資料」，首頁卡片、分類篩選和條目頁就會自動出現。

每張圖鑑卡都一樣

  • 後設資料放在 data/foods.json：名稱、英文名、分類、地區、價位、辣度、標籤、一句話介紹。
  • 內文放在 content/foods/<slug>.md，固定四段：它是什麼、怎麼吃最對味、小故事、逛夜市小提醒。
  • 分類只有四種：鹹食、甜食、飲品、炸物；標籤從固定清單挑選。

讓 AI 接手的方式

對 AI 說「依照 AGENTS.md 新增一道『滷肉飯』」，它就會：

  • 取 slug（例如 braised-pork-rice），複製範本寫好四段內文。
  • 在 JSON 最後加入一筆資料，欄位全部依規則填寫。
  • 執行 python3 scripts/check.py 自動驗證格式，通過才算完成。

規則寫得越具體，AI 每次產出的頁面就越一致。

技術

純 HTML、CSS、原生 JavaScript，沒有建置步驟，直接部署在 GitHub Pages。Markdown 由站內約 30 行的迷你轉換器在瀏覽器端轉成 HTML，完全不依賴外部函式庫。
