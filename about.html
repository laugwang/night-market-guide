關於夜市小吃圖鑑

這是一個用 AGENTS.md 驅動的小型內容網站。網站的程式只寫一次，之後每道小吃都只是一個 Markdown 檔，首頁卡片、分類篩選和條目頁都會自動產生。

三種新增方式，同一套規則

  • 一般人：到 ＋ 新增 填表單，即時預覽、即時檢查，按「送出到 GitHub」再按一次 Commit 就上線。
  • AI：對 AI 說「依照 AGENTS.md 新增一道『滷肉飯』」，它會照範本寫好檔案並自己跑驗證。
  • 開發者：複製 templates/food-template.md，執行 python3 scripts/build.py。

不管誰新增，GitHub 在部署前都會用同一支檢查程式把關，格式不對就不會上線。

每張圖鑑卡都一樣

  • 檔案開頭記錄名稱、英文名、分類、地區、價位、辣度、標籤、一句話介紹。
  • 內文固定四段：它是什麼、怎麼吃最對味、小故事、逛夜市小提醒。
  • 分類只有四種：鹹食、甜食、飲品、炸物；標籤從固定清單挑選。

技術

純 HTML、CSS、原生 JavaScript，不依賴任何框架。每次更新時，GitHub Actions 先用 Python 驗證內容、產生索引，再部署到 GitHub Pages。Markdown 由站內約 30 行的迷你轉換器在瀏覽器端轉成 HTML，完全不依賴外部函式庫。
